FactoryTwin Pro：智慧製造數位孿生 SaaS 儀表板

## 作品簡介
本作品是一個以工業 4.0 與數位孿生為主題的 HTML 型 MVP，設計成類似企業 SaaS 後台的智慧製造儀表板。使用者可切換正常生產、設備故障、AI 預測維護與需求暴增等情境，系統會即時更新產能效率、生產成本、準時交付率與設備健康度，並透過折線圖與工廠地圖呈現數位孿生監控效果。作品也加入供應商選擇與 AI 決策助理，展示管理資訊系統如何整合資料、分析風險並支援供應鏈最佳化決策。

## 核心功能說明
1. SaaS 風格企業儀表板介面。
2. 四種智慧工廠情境模擬。
3. KPI 即時更新：產能、成本、交付率、設備健康度。
4. Canvas 即時折線圖：模擬產能與交付趨勢。
5. 智慧工廠數位孿生地圖：呈現產線設備狀態。
6. 供應鏈最佳化：選擇供應商並比較成本、交期與風險。
7. AI 決策助理：依照目前情境與供應商選擇產生管理建議。

## 操作方式
1. 解壓縮資料夾。
2. 開啟 `index.html`。
3. 點擊情境模擬按鈕。
4. 切換折線圖中的「產能」與「交付」。
5. 使用供應商下拉選單選擇供應商 A、B 或 C。
6. 點擊 AI 助理下方快速問題，查看系統回覆。
7. 點擊「重置模擬」可回到初始狀態。
